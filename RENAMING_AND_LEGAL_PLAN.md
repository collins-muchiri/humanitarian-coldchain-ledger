# Renaming and legal remediation plan

## Why this is first
The repository name and description state or imply that the system was built for the International
Committee of the Red Cross. The ICRC name and the red cross emblem are protected under the Geneva
Conventions and under national legislation, including in Kenya. Unauthorised use implying
affiliation or endorsement is not a branding problem; it is a legal exposure that any international
organisation's due diligence will surface in minutes.

## Steps, in order
1. Rename the repository to humanitarian-coldchain-ledger. GitHub redirects old URLs, so existing
   links keep working.
2. Replace the description with: Cold-chain integrity ledger prototype for humanitarian supply
   chains. Independent project, not affiliated with or endorsed by any component of the
   International Red Cross and Red Crescent Movement.
3. Remove every occurrence of ICRC, International Committee of the Red Cross and any red cross or
   red crescent imagery from README, code, UI assets, commit-visible docs and issue templates.
   Search the tree case-insensitively before declaring this done.
4. Add DISCLAIMER.md at the repository root and link it from the README header.
5. Review commit history for protected names in messages that matter; rewriting history is optional
   and only worth doing if the repository is widely linked. Prefer the forward fix.
6. Record the date of completion here, and only then share the portfolio externally.

## What not to do
Do not contact the ICRC to ask for retroactive blessing of the existing name. Ask, if you ever want
a real partnership, after the rename, with the renamed project as the subject.
